# Data availability and reproducibility boundary

## Version 3 release candidate

The version 3 methodology code, schemas, tests, deterministic simulation and generated diagnostics are reproducible from public repository content.

The Romanian organisational AI example is distributed only as aggregate state counts and low-dimensional group-by-state counts. These inputs reproduce the registered outcome levels, positive-state composition and employee-band association diagnostics used for Study 1.

## Not publicly distributed

The public version 3 line does not contain:

- respondent-level survey records;
- free-text answers;
- direct or replacement response identifiers;
- IP addresses;
- precise timestamps or paradata;
- raw LimeSurvey exports;
- private ethics, DPO or editorial correspondence.

Consequently, the public package does not support respondent-level recoding, duplicate adjudication, linkage to unique firms or independent reconstruction of the transformation from restricted source exports to aggregate counts. This is an explicit evidence boundary, not a claim of end-to-end reproducibility.

## Published predecessor

The published aggregate reproduction package for version 2.0.2 is identified by DOI `10.5281/zenodo.21603732`. The final version 3.0.0 record will be created only after the methodological article, simulations, independent replication and repository outputs are frozen and aligned.

## Controlled access

No general controlled-access procedure is promised. Any future request involving restricted source material would require a documented data-protection assessment, institutional authorisation and a purpose compatible with the participant-information and consent conditions.
