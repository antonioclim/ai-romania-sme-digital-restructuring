# Changelog

All notable changes to the public reproducibility workflow are documented here.

## [3.0.0-rc1] — development

### IM-R3 literature, journal and simulation freeze — 2026-08-14

#### Added

- a bounded exact-name and adjacent-method literature-collision audit;
- an *Information & Management* journal-conversation lock;
- a hostile statistical review using the ADEMP structure;
- a frozen 432-cell simulation design;
- 4,000 planned replications per cell, implemented as four 1,000-replication seed streams;
- prespecified Monte Carlo precision, undefined-result and sparse-cell gates;
- a locked reporting order and graphical plan;
- a protocol SHA-256 record and automated freeze test;
- a verified IM-R3 DOI reference register.

#### Changed

- narrowed the novelty claim to a formal categorical state-map and inference-control audit;
- explicitly acknowledged multiverse operationalisations and measurement nonequivalence as prior art;
- increased the full replication target from 1,000 to 4,000 per cell;
- separated design freeze from full-engine execution authorisation;
- clarified that Cramér's V is an omnibus diagnostic rather than a definition-quality score.

#### Not yet final

- full-engine SeedSequence stream compliance;
- full simulation execution and result audit;
- independent Study 2;
- final article-output crosswalk;
- final *Information & Management* manuscript and declarations;
- version-specific Zenodo DOI;
- frozen `v3.0.0` release asset.

### IM-R2 formal-method and simulation-protocol consolidation — 2026-08-14

#### Added

- exact symmetric-difference decomposition for arbitrary definition pairs;
- explicit composition vectors and descriptive total variation;
- association contrasts under a common diagnostic;
- pairwise subgroup-order disagreement separating strict reversals from tie changes;
- executable tests for nested-level monotonicity, association non-monotonicity, claim-admissibility closure and coarsening boundaries;
- a candidate factorial simulation protocol with six controlled mechanisms;
- generating population, sampled true and observed layers;
- separate sampling, observation-process and total errors;
- reporting of undefined association margins and Monte Carlo standard errors;
- formal properties and proof sketches;
- an adjacent-methods novelty boundary;
- a manuscript integration blueprint.

#### Changed

- expanded the method specification and reporting checklist;
- upgraded the RC CI workflow to test formal properties and the candidate factorial protocol;
- clarified that within-broad active/project swapping preserves the broad positive boundary exactly after retention;
- clarified that CI and smoke simulations are not manuscript evidence.

### IM-R1 executable release candidate — 2026-08-14

#### Added

- a reusable Python package for Outcome-Definition Sensitivity Analysis;
- validated state-space, outcome-definition and claim models;
- definition-relation diagnostics;
- level, composition, association and subgroup-rate diagnostics;
- group-ranking and rank-reversal diagnostics;
- a conservative claim-admissibility audit;
- a command-line interface;
- an aggregate-only Romanian organisational AI example;
- deterministic smoke simulation support;
- version 3 methodological and regression tests;
- an isolated GitHub Actions workflow for the RC branch;
- formal method, reporting, ethics and AI-assistance documentation.

#### Changed

- repositioned the repository from article-specific aggregate reproduction towards a general Information Systems methodology;
- changed the development version to `3.0.0-rc1`;
- updated README, CFF, CodeMeta and Zenodo metadata for the version 3 line;
- retained version 2.0.2 aggregate material during the RC period for compatibility and provenance.
