# IM-R4 compact simulation outputs

This directory contains the compact, manuscript-facing outputs of the frozen
IM-R4 simulation programme. It does not contain human-participant records.

## Included

- full execution and convergence audits;
- reference-process results at n=250 per group;
- reference-process sample-size trace;
- observation-process stress-test summary;
- source data for the prespecified result figures;
- claim–evidence ledger;
- machine-readable phase gate.

## Not included in the Git branch

The four stream matrices contain only synthetic simulation results but are
large. They are retained in the separate IM-R4 full-evidence archive and will
be frozen into the final v3.0.0 release asset after Study 2 and the final
article-output crosswalk are complete.

## Interpretation boundary

The compact tables are conditional on the frozen synthetic mechanisms. They
are not estimates of Romanian AI adoption, empirical sampling probabilities or
universal performance guarantees for ODSA.
