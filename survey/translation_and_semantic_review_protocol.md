# Translation and semantic-review protocol

## Scope

This protocol governs any authorised analysis of narrative answers. The public release contains no respondent narrative text and no translated respondent narrative text.

## Required workflow

1. Retain the unmodified source only in an authorised private environment.
2. Identify the language at cell level rather than inferring it solely from the Romanian survey interface.
3. Review direct identifiers, organisational names, localities, websites, exact amounts and distinctive combinations before translation.
4. Redact or generalise only what is necessary to control disclosure while preserving analytical meaning.
5. Translate the disclosure-controlled text into British English.
6. Preserve negation, uncertainty, modality, temporal reference and organisational level.
7. Distinguish intention, budgeting, experimentation, piloting, implementation and routine use.
8. Check the English rendering against the disclosure-controlled source text.
9. Record the translator, verification status and any interpretive intervention.
10. Assign semantic categories only after translation verification and contextual reading.

## Prohibited shortcuts

Word counts, sentiment scores, keyword hits and automated translation are not substitutes for contextual interpretation. No analytical category should be assigned solely by an automated system. A phrase such as “we tested” must not be treated as evidence of routine use, while “we plan to” must not be recoded as implementation.

## Publication statement

A publication may state that Romanian narrative responses were translated and verified by the author only after the corresponding cell-level record has been completed. This public release makes no such claim because respondent narratives are not distributed here.
