# Provenance and version boundary

## Version 3 methodology line

Version `3.0.0-rc1` develops Outcome-Definition Sensitivity Analysis as a reusable Information Systems methodology. The formal engine, tests and simulation are new version 3 components. The Romanian organisational AI example is retained as an aggregate-only worked example and regression case.

The version 3 example begins at the aggregate-count layer. It does not establish that each completed response represents a unique firm and it does not make the voluntary response set representative of Romanian SMEs. The empirical unit is one completed response. Employee-band labels provide an analytical classification rather than a verified legal SME status.

## Study 1 source lineage

The restricted source environment contains paired survey exports used to verify coded values and Romanian labels. The original LimeSurvey definition file has not been located. The public questionnaire documentation is therefore a source-faithful reconstruction, not the original platform configuration.

The collection window for the completed responses used in the current analysis is 17–31 August 2025. The public version 3 example preserves only the aggregate quantities required for the registered definitions and low-dimensional association diagnostics.

## Published predecessor

Version `2.0.2`, DOI `10.5281/zenodo.21603732`, is the current published aggregate reproduction package. It remains the archival predecessor while version 3 is under development.

Version `3.0.0-rc1` does not claim a new DOI and must not be represented as the final archive. The final `v3.0.0` release will require exact alignment among the Git tag, release asset, Zenodo record, article tables, article figures, method specification and claim–evidence ledger.

## Historical material

Earlier repository and deposit versions document superseded article framings and data architectures. Their existence must not be interpreted as restoring earlier claims, validating earlier metadata or authorising respondent-level material for the version 3 release. Governance questions concerning historical public artefacts remain separate from the scientific validity of the current aggregate-only implementation.
